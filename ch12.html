บทที่ 12หลักการนับเบื้องต้น
1. ก่อนนับ ต้องรู้ว่าอะไรถือเป็นหนึ่งแบบ2. หลักการคูณกับหลักการบวก3. แฟกทอเรียลและการเรียงของต่างกัน4. การเรียงของที่มีของเหมือนกัน5. การเรียงรอบวง6. การเลือกแบบไม่สนลำดับ7. เครื่องมือเมื่อมีเงื่อนไข8. แนวที่เลือกฝึก: รหัสที่มีเลขบังคับ

1. ก่อนนับ ต้องรู้ว่าอะไรถือเป็นหนึ่งแบบ

หลักการนับหาจำนวนผลลัพธ์โดยไม่แจงทุกแบบ ก่อนคำนวณตอบสามเรื่อง:

  • กำลังสร้างอะไร เช่น รหัส จำนวนเต็ม แถวคน หรือกลุ่มคน
  • ใช้สิ่งเดิมซ้ำได้หรือไม่ และมีตำแหน่งใดถูกจำกัด
  • ถ้าสลับลำดับ หมุน หรือเปลี่ยนตำแหน่ง ยังถือว่าเป็นแบบเดิมหรือไม่

เช่น คนสองคนสลับหน้าที่หัวหน้ากับรอง จะได้การมอบหน้าที่คนละแบบ แต่ถ้าเลือกเป็นทีมสองคน ทีมเดิมยังเป็นทีมเดิมแม้เขียนชื่อสลับกัน

2. หลักการคูณกับหลักการบวก

หลักการคูณ: ถ้าทำงานให้เสร็จต้องผ่านหลายขั้น และสำหรับทุกทางเลือกในขั้นก่อนหน้า ขั้นถัดไปมีจำนวนทางเลือกตามที่กำหนด ให้นำจำนวนทางเลือกแต่ละขั้นมาคูณกัน

เช่น เลือกเสื้อ 2 แบบ แล้วเลือกกางเกง 3 แบบ โดยจับคู่ได้ทุกแบบ จะได้ 2×3=6 ชุด แต่ละชุดต้องมีทั้งเสื้อและกางเกง

ห้ามใช้ซ้ำ → จำนวนตัวเลือกขั้นต่อไปลดลงได้ คูณจำนวนที่เหลือให้ถูก ไม่จำเป็นต้องเท่ากันทุกขั้น

หลักการบวก: ถ้างานสำเร็จได้ด้วยกรณีใดกรณีหนึ่ง และกรณีเหล่านั้นไม่ซ้ำกัน ให้นับแต่ละกรณีแล้วบวก

ของขวัญ 1 ชิ้น เลือกจากเสื้อ 2 แบบหรือกางเกง 3 แบบ กรณีไม่ซ้ำ จึง 2+3=5 แบบ ต่างจากชุดแต่งตัวที่ต้องใช้ทั้งสองชิ้น

ถ้ากรณีทับกัน การบวกตรง ๆ จะนับบางผลลัพธ์ซ้ำ ต้องแยกกรณีใหม่ให้ไม่ทับกัน หรือหักส่วนที่นับซ้ำออก เช่น เมื่อ A,B เป็นเซตจำกัด n(A∪B)=n(A)+n(B)−n(A∩B)

ขั้นต่อไปมีตัวเลือกต่างกันตามทางก่อนหน้า → แยกกรณี → คูณภายใน → บวกแต่ละกรณี

ระวัง: อย่าตัดสินจากคำว่า “และ” หรือ “หรือ” เพียงคำเดียว ให้ดูว่าผลลัพธ์หนึ่งแบบต้องผ่านกี่ขั้น และแต่ละกรณีซ้ำกันหรือไม่

3. แฟกทอเรียลและการเรียงของต่างกัน

บทนิยาม: สำหรับจำนวนเต็มบวก n ให้ n!=n(n−1)(n−2)…1 และกำหนด 0!=1

การเรียงของต่างกัน n ชิ้นเป็นแถว ใช้ครบทุกชิ้น จะได้ n! แบบ เพราะตำแหน่งแรกเลือกได้ n ทาง แล้วเหลือ n−1 ทาง ลดลงไปจนเหลือ 1 ทาง

ถ้าเลือกของต่างกัน n ชิ้นมาเรียงเพียง r ตำแหน่งโดยไม่ซ้ำ เมื่อ n,r เป็นจำนวนเต็มและ 0≤r≤n จะได้

P(n,r)=n!(n−r)!

สำหรับ r≥1 นี่คือ n(n−1)…(n−r+1); กรณี r=0 มีการไม่เลือกอะไรอยู่หนึ่งแบบ

ถ้าแต่ละตำแหน่งเลือกจากของ n ชนิดได้อย่างอิสระและใช้ซ้ำได้ โดย n เป็นจำนวนเต็มบวกและ r เป็นจำนวนเต็มไม่ลบ จะมี nr แบบ แทนการลดจำนวนตัวเลือกลงทุกขั้น

ระวัง: สูตร n! และ P(n,r) ใช้กับของต่างกันและไม่ซ้ำ หากมีข้อจำกัดตำแหน่ง ต้องจัดการข้อจำกัดก่อน ไม่ใส่สูตรทันที

4. การเรียงของที่มีของเหมือนกัน

ถ้ามีของรวม n ชิ้น แบ่งเป็นชนิดที่เหมือนกันภายในชนิด จำนวน n1,n2,…,nk ชิ้น โดย n1+n2+…+nk=n การเรียงเป็นแถวใช้ครบทุกชิ้นมี

n!n1!n2!…nk! แบบ

n! นับเหมือนทุกชิ้นต่างกัน แต่สลับชนิดเดียวกันไม่เกิดแบบใหม่ จึงหารจำนวนที่นับซ้ำ

เช่น A,A,B เรียงได้ 3!2!=3 แบบ คือ AAB, ABA, BAA

ระวัง: ของจะเหมือนกันหรือไม่ขึ้นกับโจทย์ คนที่ใส่เสื้อสีเดียวกันยังเป็นคนต่างกัน ไม่หารแฟกทอเรียลเพียงเพราะสีเหมือนกัน

5. การเรียงรอบวง

เมื่อเรียงของต่างกัน n ชิ้นรอบวง โดย n≥1 และการหมุนทั้งวงถือเป็นแบบเดิม แต่ภาพสะท้อนยังถือเป็นคนละแบบ จะมี (n−1)! แบบ

ตรึงหนึ่งชิ้นเป็นจุดอ้างอิง แล้วเรียงอีก n−1 ชิ้น เพราะการหมุนทั้งวงไม่ได้เปลี่ยนว่าใครอยู่ข้างใคร

เช่น คนต่างกัน 4 คนรอบโต๊ะ เมื่อหมุนทั้งวงถือเป็นแบบเดิม ตรึงหนึ่งคนแล้วเรียงอีกสามคนได้ 3!=6 แบบ

ระวัง: ถ้าเก้าอี้มีหมายเลขกำกับและตำแหน่งที่นั่งถือว่าต่างกัน จะนับเหมือนตำแหน่งต่างกัน n ตำแหน่ง จึงได้ n! สำหรับคนต่างกัน n คน ไม่ใช้ (n−1)! และไม่หาร 2 เพิ่มถ้าโจทย์ไม่ได้ถือว่าภาพสะท้อนเหมือนกัน

6. การเลือกแบบไม่สนลำดับ

ถ้าเลือกของต่างกัน n ชิ้นมา r ชิ้น โดยไม่ซ้ำและไม่สนลำดับ เมื่อ n,r เป็นจำนวนเต็มและ 0≤r≤n จะมี

C(n,r)=n!r!(n−r)! แบบ

C(n,r) เขียนเป็นตัวจัดหมู่แบบคอลัมน์ได้ ความหมายเดียวกัน:

(nr)=C(n,r)

การเลือกชุดเดียวกันถูก P(n,r) นับซ้ำ r! ครั้งจากการเรียงของที่เลือก จึงหาร r! ออก และมี C(n,r)=C(n,n−r) เพราะเลือกของที่เอากับเลือกของที่เหลือให้ข้อมูลชุดเดียวกัน

เช่น จากนักเรียน 5 คน เลือกหัวหน้ากับรองโดยห้ามเป็นคนเดียวกัน มี 5×4=P(5,2)=20 แบบ แต่เลือกทีมสองคนมี C(5,2)=202!=10 ทีม

เกณฑ์เลือกวิธี: ลองสลับของที่เลือก ถ้าคำตอบเปลี่ยน เช่น สลับหน้าที่หรือตำแหน่ง ให้คิดแบบเรียง; ถ้าผลลัพธ์เดิม เช่น สมาชิกทีมเดิม ให้คิดแบบเลือกไม่สนลำดับ

ระวัง: คำว่า “เลือก” อาจตามด้วยการมอบหน้าที่ จึงไม่ได้แปลว่าต้องใช้ C(n,r) เสมอ

7. เครื่องมือเมื่อมีเงื่อนไข

เงื่อนไขวิธีเริ่มสิ่งที่ต้องตรวจ
บางตำแหน่งจำกัดตัวเลือกนับตำแหน่งนั้นก่อน แล้วเติมที่เหลือตัวเลือกที่ใช้ไปแล้วและข้อห้ามตำแหน่งอื่น
ของที่กำหนดต้องอยู่ติดกันรวมเป็นหนึ่งกลุ่ม เรียงกลุ่มกับของที่เหลือ แล้วเรียงภายในกลุ่มแต่ละผลลัพธ์ต้องเกิดจากการแบ่งกลุ่มเพียงวิธีเดียว
ของสองชิ้นห้ามติดกันนับทั้งหมดลบกรณีสองชิ้นติดกัน หรือเรียงของอื่นแล้วเลือกช่องแทรกนิยามช่องหัวท้ายและห้ามใส่หลายชิ้นในช่องเดียวถ้าต้องแยกกัน
ต้องมีอย่างน้อยหนึ่งนับทั้งหมดลบกรณีไม่มีเลยกรณีที่ลบต้องเป็นส่วนเติมเต็มตรงเงื่อนไข
มีจำนวนที่กำหนดแน่นอนเลือกตำแหน่งของสิ่งนั้น แล้วเติมที่เหลือห้ามให้ตำแหน่งที่เหลือสร้างสิ่งนั้นเพิ่ม

แบ่งกรณีต้อง ครอบคลุมทั้งหมดและไม่ทับกัน

8. แนวที่เลือกฝึก: รหัสที่มีเลขบังคับ

ก่อนเติมรหัส ให้แยก รหัส ออกจาก จำนวนหลายหลัก รหัสอาจเริ่มด้วย 0 ได้ตามโจทย์ แต่จำนวนสามหลักเริ่มด้วย 0 ไม่ได้ จากนั้นตรวจว่าเลขซ้ำได้หรือไม่ และต้องมีเลขที่บังคับกี่ครั้ง

ไม่ซ้ำและบังคับเลขหนึ่งตัว → เลือกตำแหน่งเลขนั้นก่อน → เติมที่เหลือ ไม่ต้องตามว่าเลขบังคับเกิดขั้นใด

ตัวอย่าง รหัส 3 ตำแหน่งใช้เลข 0,1,2,3,4 ไม่ซ้ำ ต้องมี 0 และอนุญาตให้เริ่มด้วย 0:

  • เลือกตำแหน่งของ 0 ได้ 3 ทาง
  • เติมสองตำแหน่งที่เหลือด้วยเลข 1–4 ได้ 4 ทาง แล้วเหลือ 3 ทาง
  • รวม 3×4×3=36 รหัส

ถ้าเปลี่ยนเป็น จำนวนสามหลัก ที่ต้องมี 0 และไม่ซ้ำ เลข 0 อยู่ได้เฉพาะหลักสิบหรือหลักหน่วย จึงเหลือ 2×4×3=24 จำนวน

หากอนุญาตให้เลขซ้ำและต้องมี 0 อย่างน้อยหนึ่งตัว วิธีเลือกตำแหน่งของ 0 หนึ่งตำแหน่งแล้วเติมทุกเลขจะนับรหัสที่มี 0 หลายตัวซ้ำ ให้ใช้ส่วนเติมเต็มแทน เช่น รหัส 3 ตำแหน่งจากเลข 0–4 ที่ซ้ำได้และเริ่ม 0 ได้ มีทั้งหมด 53 รหัส และไม่มี 0 เลย 43 รหัส จึงมี 0 อย่างน้อยหนึ่งตัว 53−43=61 รหัส

ระวัง: “มีหนึ่งตัวพอดี” ต่างจาก “มีอย่างน้อยหนึ่งตัว” และการเลือกตำแหน่งที่จำกัดก่อนทำได้เมื่อยังตามข้อจำกัดของตำแหน่งอื่นครบ
