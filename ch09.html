1. เมทริกซ์และขนาด

เมทริกซ์จัดจำนวนเป็นแถวและหลัก ใช้เก็บข้อมูลและเขียนระบบสมการ

  • ขนาด m×n: m แถว n หลัก อ่าน แถวก่อนหลัก
  • สมาชิก aij: แถว i หลัก j
  • เมทริกซ์เท่ากัน: ขนาดเท่ากัน และสมาชิกตำแหน่งเดียวกันเท่ากันทุกตัว

ในข้อความนี้ ; แบ่งแถว เช่น A=[1234] มีแถวแรก 1,2 แถวที่สอง 3,4 ขนาด 2×2

เมทริกซ์จัตุรัส: แถวเท่ากับหลัก เช่น 2×2, 3×3 เส้นทแยงมุมหลักผ่านตำแหน่ง (1,1), (2,2), …

2. การบวก ลบ คูณด้วยจำนวน และทรานสโพส

การดำเนินการวิธีทำ/เงื่อนไข
บวก–ลบขนาดเท่ากัน; ทำกับสมาชิกตำแหน่งเดียวกัน
คูณด้วย kคูณทุกสมาชิกด้วย k
ทรานสโพส ATสลับแถวเป็นหลัก; ขนาด m×n เปลี่ยนเป็น n×m

ตัวอย่างคูณด้วยจำนวน:

3[1234]=[36912]

ตัวอย่างทรานสโพส:

A=[123456] ให้ AT=[142536] ขนาด 2×3 → 3×2

สมบัติ: (AT)T=A, (A+B)T=AT+BT, (kA)T=kAT

เมทริกซ์สมมาตร: จัตุรัสที่ AT=A สมาชิกสองฝั่งเส้นทแยงมุมหลักตรงกันเป็นคู่

ระวัง: ทรานสโพสสลับตำแหน่ง ไม่เปลี่ยนเครื่องหมาย

3. การคูณเมทริกซ์

A: m×n, B: n×p → คูณ AB ได้ ผลขนาด m×p

หลักของตัวหน้า = แถวของตัวหลัง สมาชิกตำแหน่ง (i,j) หาโดย นำแถว i ของ A กับหลัก j ของ B มาคูณคู่ที่ตรงกันแล้วบวก

เช่น A=[1234], B=[2013] สมาชิก (1,1) คือ 1(2)+2(1)=4 ทำครบได้ AB=[461012]

สมบัติ เมื่อขนาดทำให้การดำเนินการมีความหมาย:

  • A(BC)=(AB)C
  • A(B+C)=AB+AC
  • (A+B)C=AC+BC
  • (AB)T=BTAT

ระวัง: โดยทั่วไป AB≠BA; AB คูณได้แต่ BA อาจไม่ได้ และการคูณนี้ไม่ใช่คูณสมาชิกตำแหน่งเดียวกัน

4. เมทริกซ์ศูนย์ เอกลักษณ์ และสามเหลี่ยม

ชนิดลักษณะ/สมบัติ
ศูนย์ Oทุกสมาชิกเป็น 0; A+O=A เมื่อขนาดเท่ากัน
เอกลักษณ์ Inจัตุรัส n×n เส้นทแยงมุมหลักเป็น 1 ที่เหลือเป็น 0
สามเหลี่ยมบนจัตุรัสที่ใต้เส้นทแยงมุมหลักเป็น 0 ทั้งหมด
สามเหลี่ยมล่างจัตุรัสที่เหนือเส้นทแยงมุมหลักเป็น 0 ทั้งหมด

ตัวอย่าง I2=[1001] ทำหน้าที่เหมือน 1 ในการคูณ สำหรับ A ขนาด m×n ใช้ ImA=A, AIn=A

ตัวอย่างสามเหลี่ยมบน [21−3042005] และสามเหลี่ยมล่าง [200140−325]

ชื่อบน/ล่างบอกด้านที่อาจไม่เป็นศูนย์ สมาชิกบนเส้นทแยงมุมหลักไม่จำเป็นต้องเป็น 1 และอาจเป็น 0 ได้ ใช้สามเหลี่ยมทั้งใน RO และการหา det

ระวัง: เลือกขนาด I ให้คูณได้; A2=AA ไม่ใช่ยกกำลังสองทุกสมาชิก

5. ดีเทอร์มิแนนต์

det⁡(A) เป็น จำนวน จากเมทริกซ์จัตุรัส ใช้ตรวจผกผันและแก้ระบบสมการ

  • A=[abcd]: det⁡(A)=ad−bc คือคูณทแยงลงลบคูณทแยงขึ้น
  • A=[abcdefghi]:det⁡(A)=aei+bfg+cdh−ceg−bdi−afh

วิธี 3×3: เขียนสองหลักแรกต่อท้าย บวกผลคูณทแยงลงขวาสามแนว ลบผลคูณทแยงขึ้นขวาสามแนว ใช้วิธีนี้เฉพาะ 3×3

สิ่งที่ทำ/ลักษณะเมทริกซ์ผลต่อ det
สลับสองแถวเปลี่ยนเครื่องหมาย
คูณแถวหนึ่งด้วย kคูณ det ด้วย k
บวกพหุคูณของแถวหนึ่งเข้าอีกแถวค่าเดิม
มีแถวศูนย์ หรือสองแถวเท่ากัน/เป็นสัดส่วนdet=0
สามเหลี่ยมบนหรือล่างผลคูณสมาชิกเส้นทแยงมุมหลัก

สมบัติแถวใช้กับหลักได้ด้วย

ระวัง: det ไม่ใช่เมทริกซ์ และใช้กับเมทริกซ์จัตุรัสเท่านั้น

6. เมทริกซ์ผกผัน

ผกผัน A−1 คูณกับ A แล้วเป็นเอกลักษณ์: AA−1=A−1A=I

เมทริกซ์จัตุรัสมีผกผันก็ต่อเมื่อ det⁡(A)≠0

ถ้า A=[abcd], ad−bc≠0:

A−1=(1ad−bc)[d−b−ca]

สลับ a,d → เปลี่ยนเครื่องหมาย b,c → คูณทุกตัวด้วยส่วนกลับ det

เมื่อเมทริกซ์ที่เกี่ยวข้องมีผกผัน:

  • (A−1)−1=A
  • (AB)−1=B−1A−1
  • (AT)−1=(A−1)T

ระวัง: ผกผันผลคูณกลับลำดับ; A−1 ไม่ใช่ส่วนกลับของสมาชิกแต่ละตัว

วิธี 2 การดำเนินการตามแถว (RO)

วิธี 3 กฎของคราเมอร์

ใช้เมื่อจำนวนสมการเท่าจำนวนตัวแปร และ D=det⁡(A)≠0 ระบบจึงมีคำตอบเดียว

สร้าง Dx,Dy,Dz โดย แทนหลักของตัวแปรนั้นด้วยหลักค่าขวา B หลักอื่นคงเดิม แล้วหารด้วย D:

x=DxD,y=DyD,z=DzD

8. แนวข้อสอบที่เน้น: ใช้สมบัติดีเทอร์มิแนนต์แทนการคูณเมทริกซ์ทั้งหมด

ให้ค่า det มาแล้วถาม det ของนิพจน์ใหม่ ลองใช้สมบัติก่อนคูณสมาชิกทั้งหมด เมื่อ A,B จัตุรัสขนาด n×n:

  • det⁡(AB)=det⁡(A)det⁡(B)
  • det⁡(AT)=det⁡(A)
  • det⁡(A−1)=1det⁡(A) เมื่อ det⁡(A)≠0
  • det⁡(kA)=kndet⁡(A)
  • det⁡(In)=1 และ det⁡(kIn)=kn

คูณทั้งเมทริกซ์ด้วย k คือคูณทั้ง n แถว จึงมีตัวคูณ k รวม n ครั้ง เช่น A ขนาด 3×3: det⁡(2A)=23det⁡(A)=8det⁡(A)

ตรวจขนาด → แยกผลคูณใน det → ใช้สมบัติทรานสโพส/ผกผัน → จัดตัวคูณตามขนาด → แทนค่า

ระวัง: ผกผันต้อง det≠0; คูณทั้งเมทริกซ์ได้ kn แต่คูณแถวเดียวได้ k; โดยทั่วไป det⁡(A+B)≠det⁡(A)+det⁡(B) จึงแยกผลบวกแบบผลคูณไม่ได้
