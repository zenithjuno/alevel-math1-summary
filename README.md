## ใช้งาน

- **เลือกบท** จากเมนูด้านบน หรือกดการ์ดบทในหน้าแรก
- **ค้นทุกบท** จากช่องค้นในหน้าแรก กดผลค้นแล้วไปที่หัวข้อนั้นพร้อมไฮไลต์คำ
- **ค้นในบท** จากช่องค้นต้นบท บอกจำนวนที่เจอและพาไปจุดแรก
- **อ่านต่อ** จากหน้าแรก กลับไปบทและตำแหน่งที่อ่านค้างไว้
- **Aa** ขยาย/ย่อตัวอักษร
- **QR** แสดง QR code ของหน้านี้หรือหน้าแรก สำหรับฉายให้คนอื่นสแกนเข้าเว็บ
- โหมดมืด/สว่างเปลี่ยนตามการตั้งค่าเครื่อง

## สำหรับผู้ดูแล

repo นี้เก็บเฉพาะไฟล์เว็บที่สร้างแล้ว (static HTML) และเผยแพร่ผ่าน GitHub Pages จาก branch `main`

- ต้นฉบับเนื้อหาและตัวสร้างเว็บ (`build_course-web.py`) อยู่ใน workspace ของผู้เขียน **อย่าแก้ HTML ใน repo นี้โดยตรง** เพราะการสร้างครั้งถัดไปจะเขียนทับ
- สูตรเป็น MathML ที่เบราว์เซอร์แสดงเอง ไม่ต้องโหลดสคริปต์คณิต; รูปประกอบเป็น SVG
- ไม่มีการเก็บข้อมูลผู้ใช้ ค่าที่จำไว้ (ขนาดตัวอักษร บทที่อ่านค้าง) อยู่ใน `localStorage` ของเครื่องผู้อ่านเท่านั้น
- `search-index.json` คือดัชนีค้นหาทุกบท สร้างพร้อมหน้าเว็บ
